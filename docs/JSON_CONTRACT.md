# Geometry JSON and FE input

The common geometry input contains these fields:

| Field | Meaning |
| --- | --- |
| `schema` | Must be `pw85-ellipsoids-export`. |
| `periodic` | Must be `true` for the periodic FE construction route. |
| `box` | Three positive box lengths in micrometres. |
| `particles` | Physical ellipsoids represented by `id`, `a`, `b`, `c` and `p`. |

For each particle, `id` identifies the particle, `a` and `b` are positive physical semiaxes in micrometres, `c` is the three-component centre vector, and `p` is the three-component direction vector. The ellipsoid is axisymmetric with semiaxes `(a,b,b)`; `c` is not a scalar semiaxis. Equivalent diameter `d` and aspect ratio `rho` correspond to `a=(d/2)*rho^(2/3)` and `b=(d/2)*rho^(-1/3)`.

The packaged input [examples/vf30_mixed_ar12_20/geometry.json](../examples/vf30_mixed_ar12_20/geometry.json) contains the geometry fields above. Its FE input route requires the packaged file's exact identity and the bound source identity; editing that input invalidates this route. The packaged geometry is independent of geometry generated by the example command.

User-generated geometry requires an adjacent `geometry_acceptance.json` with schema `cbge-tafe-geometry-acceptance-v2.2`. It binds the exact geometry SHA-256, source identity, resolved configuration, required final audit verdicts and seed lineage. When orientation control is enabled, the native target-alignment audit must pass at the configured tolerance. Required GEO face, edge and corner violations must be within their tolerances, and physical PW and periodic checks must pass.

Generated exports may also contain `optimization_summary`, constraints, diagnostics and other runtime metadata. These additional fields are not present in the packaged geometry example and are not part of the minimal geometry field list above.

Keep a generated geometry and its acceptance record unchanged before FE construction. Missing required acceptance information, inconsistent hashes, incomplete audits or non-native generation status prevent user-generated input from being admitted. Failed or exhausted geometry requests do not export an accepted geometry.
